# Assembly Language Tasks

This repository contains simple Assembly Language programming tasks completed as part of my university coursework.

## 📚 Course

**Assembly Language**

## 📝 Description

These tasks are designed to practice the basic concepts of Assembly Language programming, including instructions, registers, data movement, arithmetic operations, loops, and basic program structure.

## 📂 Tasks

* Basic Assembly Programs
* MOV Instruction
* Arithmetic Operations
* Registers
* Increment & Decrement
* Input/Output
* Loops and Other Basic Tasks

## 🛠️ Tools

* Assembly Language
* EMU8086 / 8086 Simulator

## 🎯 Purpose

The purpose of these tasks is to build a basic understanding of 8086 Assembly Language and improve programming and problem

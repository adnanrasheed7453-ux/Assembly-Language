# Assembly Language Tasks

This repository contains a collection of basic **8086 Assembly Language** tasks completed for Assembly Language Lab practice.

## Tasks Included

### Q1 - Display Name

Displays a name on the screen using Assembly Language.

**File:** `q1_name.asm`

### Q2 - Display Two Lines

Displays two messages on separate lines.

**File:** `q2_two_lines.asm`

### Q3 - Display ABC

Displays the characters **A, B, and C** using the `MOV` and `INT 21H` instructions.

**File:** `q3_abc.asm`

### Q4 - You Entered

Takes a character as input from the user and displays the entered character.

**File:** `q4_you_entered.asm`

### Q5 - Digit Conversion

Takes a digit as input, converts it between ASCII and numeric form, and displays the result.

**File:** `q5_digit_convert.asm`

### Q6 - Enter Letter

Prompts the user to enter a letter and then displays the entered letter.

**File:** `q6_enter_letter.asm`

## Concepts Used

* 8086 Assembly Language
* Registers
* `MOV` instruction
* `INT 21H`
* Keyboard Input
* Screen Output
* ASCII Characters
* Basic Flags
* DOS Interrupts

## Purpose

The purpose of these tasks is to practice basic **8086 Assembly Language instructions**, input/output operations, ASCII conversion, and CPU flags.

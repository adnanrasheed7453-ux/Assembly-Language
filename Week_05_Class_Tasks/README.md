# Assembly Language Tasks

## 📘 About This Repository
This repository contains my Assembly Language tasks completed as part of my coursework. These programs are written in 8086 Assembly Language and practiced using EMU8086.

## 📂 Tasks Included

1. **Jump False** – Understanding conditional jumps and program flow.
2. **While Loop** – Using loops to repeat instructions.
3. **Greater Number / Greater Digit** – Comparing numbers and finding the greater value.
4. **If-Else Character** – Using conditional statements to classify a character.
5. **Additional Assembly Tasks** – Practicing different instructions, comparisons, and logical operations.

## 🛠️ Tools Used
- 8086 Assembly Language
- EMU8086 Emulator

## 🎯 Learning Objectives
- Understand conditional jumps and loops.
- Compare numbers and characters.
- Practice assembly instructions.
- Improve logical thinking and problem-solving skills.

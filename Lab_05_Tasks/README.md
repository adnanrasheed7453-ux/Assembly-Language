# Assembly Language Tasks

This repository contains three basic Assembly Language programs developed as part of my COAL Lab practice at Superior University Lahore.

## Tasks Included

### 1. Classify Character
- Takes a character as input.
- Classifies the character according to the program's conditions.

### 2. Largest of Three Numbers
- Takes three numbers as input.
- Compares the numbers using conditional jumps.
- Displays the largest number.

### 3. Triangle
- Takes the required input values.
- Uses comparison instructions and conditional jumps to check the given conditions.

## Concepts Used
- 8086 Assembly Language
- EMU8086
- Variables and Registers
- Comparison Instructions (`CMP`)
- Conditional Jumps (`JE`, `JG`, `JL`)
- Keyboard Input and Output using `INT 21H`

## Tools
- EMU8086 Emulator

## Purpose
These programs helped me practice conditional statements, comparisons, keyboard input, and decision-making in Assembly Language.
